# Public images

Letakkan aset publik di sini.

- `placeholder-pesantren.jpg` (≥1200×630) — fallback gambar saat data dari API tidak punya gambar. Komponen `SmartImage` otomatis pakai file ini.
- `icon-192.png`, `icon-512.png` — letakkan di `public/` untuk PWA. Anda bisa replace dengan logo pesantren.

Konvensi PWA mengharapkan ikon di root `public/icon-192.png` & `public/icon-512.png`. Manifest mengarah ke `/icon-192.png` dan `/icon-512.png`.
