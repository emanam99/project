# API MD Twustha (PHP / Slim)

Backend aplikasi memakai **PHP Slim** di folder ini (`public/index.php`), bukan Google Apps Script.

- Endpoint: base URL misalnya `http://localhost/mdtwustha/api/public` atau `https://api.mdtw.my.id/public`
- Frontend React memanggil client di `app/src/api/apiClient.ts`
- Migrasi DB: `php migrate.php` dari folder `api`

Jangan menambah atau mengarahkan integrasi ke Apps Script / Google Sheet.
